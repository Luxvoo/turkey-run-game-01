A turkey escape game built for the make.fun bounty
[turkey-run-game-01](https://make.fun/bounty/turkey-run-game-01).

Help Gobble the turkey escape the farm and reach the safety of the forest
1200 metres away. Gobble runs across rolling hills past the barn while the
pace keeps rising through five levels. Jump fences, hay bales and foxes,
duck under the farmer's net, and grab corn along the way for bonus points.
Three hearts stand between Gobble and capture; reach the forest to win.

## Controls

- Jump: Space, Arrow Up, W, the Jump button, or tap the right side of the game
- Duck: Arrow Down, S, the Duck button, or tap the left side of the game
- Pause: P, Escape, or the Pause button
- Restart: R or the Start / Restart button

## How to run

```sh
python3 main.py
```

This writes `/output/entry.html` (the complete game as one static HTML file
with inline CSS and JavaScript, no external references) and four 1600x900
screenshots under `/output/screenshots/`. Open `entry.html` in any browser
to play. No network access is needed.
